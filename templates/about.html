About Digital Signature

A simple platform for digitally signing documents and verifying their authenticity.

What does it do?

The application allows users to sign documents digitally and later verify whether a document has been modified after signing.

How it works

Signing

The document is hashed using SHA-256. The hash is then signed using the user's Ed25519 private key.

Verification

The document hash and digital signature are checked using the signer's public key.

Security technologies

SHA-256
File integrity
Ed25519
Digital signatures
Fernet

Application data

A valid signature confirms that the signed content matches the original content and that the signature can be verified with the associated public key.
